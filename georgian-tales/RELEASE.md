# Выпуск в Google Play — по шагам

Приложение уже готово к оплате через Google Play: в нём есть подписка (месяц и год), бесплатная часть, восстановление покупок, родительская проверка перед оплатой, работа без интернета, значки и политика конфиденциальности. Остались шаги, которые делаются только на ваших аккаунтах.

## 1. Что нужно завести (делаете вы)
1. **Аккаунт разработчика Google Play** — https://play.google.com/console, разовый взнос $25. Для детских приложений Google проверяет личность, это занимает несколько дней.
2. **Домен** для приложения, например `zghaprebi.ge` (или любой другой — тогда поменяем его в файлах ниже).
3. **Cloudflare** (бесплатно) — на нём будут лежать само приложение (Cloudflare Pages) и маленький сервер проверки оплаты (Cloudflare Worker).

## 2. Сайт приложения (Cloudflare Pages)
Загрузить всю папку `georgian-tales/` (кроме `billing-worker/`, `android/`, `tools/`) в Cloudflare Pages и привязать домен. После этого приложение открывается по адресу `https://zghaprebi.ge/` и ставится на телефон как приложение.

## 3. Android-приложение (Trusted Web Activity)
Из сайта собирается настоящее приложение для Google Play инструментом Bubblewrap:
```
npm i -g @bubblewrap/cli
cd android
bubblewrap init --manifest https://zghaprebi.ge/manifest.webmanifest   # настройки уже в twa-manifest.json
bubblewrap build                                                       # получится app-release-bundle.aab
```
Bubblewrap выдаст отпечаток ключа (SHA-256). Его нужно положить на сайт в файл `/.well-known/assetlinks.json` — тогда Android доверяет сайту и открывает его без адресной строки. Файл Bubblewrap создаёт сам (`assetlinks.json`).

## 4. Подписки в Play Console
Monetize → Subscriptions → создать два продукта с **точно такими id**:
| id | период | цена (предложение) | пробный период |
|---|---|---|---|
| `premium_month` | 1 месяц | 9,99 ₾ | 7 дней |
| `premium_year` | 1 год | 59,99 ₾ | 7 дней |

Цены и пробный период задаются в Play Console — приложение само берёт их оттуда и показывает в валюте покупателя. Менять код для смены цены не нужно.

## 5. Сервер проверки оплаты (Cloudflare Worker)
Google возвращает деньги за покупку, если её не подтвердить в течение 3 дней, поэтому каждая покупка проверяется сервером.
1. Play Console → Settings → API access → создать **сервисный аккаунт** с правом «Просмотр финансовых данных, управление заказами и подписками». Скачать его ключ (JSON).
2. ```
   cd billing-worker
   npx wrangler secret put GOOGLE_SA_JSON      # вставить содержимое ключа — только сюда, никому его не пересылайте
   npx wrangler deploy
   ```
3. Адрес воркера (например `https://zghaprebi-billing.<имя>.workers.dev/verify`) вписать в `index.html` в `BILLING.verifyUrl`.

## 6. Перед выпуском
- В `index.html` выключить тестовый режим по умолчанию: `let testMode = store.get('test', true)` → `false` (сейчас всё открыто, чтобы вы могли проверять).
- В `privacy.html` вписать контактную почту и разместить страницу на сайте; ссылку указать в Play Console.
- Play Console → Policy → **Target audience**: возраст 3–8 (программа «Для семей»). Data safety: «данные не собираются и не передаются»; микрофон — «только по выбору родителя, хранится на устройстве».
- Сначала выпустить во **внутреннее тестирование** и купить подписку тестовым аккаунтом (лицензионный тестер в Play Console — покупки бесплатные).

## Что платно, что бесплатно (сейчас в приложении)
- **Бесплатно:** по 2 первые сказки в каждом разделе (8 сказок), 10 первых раскрасок, наклейки, страница ребёнка.
- **По подписке:** все сказки (≈150), все раскраски (100+), голос мамы или папы, новые сказки каждую неделю.
